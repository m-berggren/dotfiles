# dotfiles
Dotfiles for GNU Stow usage

## Details
**OS**: Arch Linux <br>
**VM**: Hyprland <br>
**Terminals**: Alacritty & Ghostty <br>
**Shell**: Fish with Starship customization <br>
**Themes**: Mainly Kanagawa, Everforest

## Applications in use
- Anki
- Docker
- Logseq
- Neovim
- Podman
- Postman
- Tailscale
- VsCode
- Zen Browser
- Yazi

## Running
Install everything through `make all` or `make`.
