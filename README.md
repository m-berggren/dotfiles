# dotfiles
Dotfiles for GNU Stow usage

## Details
**OS**: Arch Linux, using Omarchy <br>
**VM**: Hyprland <br>
**Terminal**: Alacritty & Ghostty <br>
**Shell**: Fish together with Starship <br>
**Themes**: Varying (from within Omarchy) but mainly Kanagawa, Everforest

## Applications in use
- Anki
- Docker
- Logseq
- Neovim
- Podman
- Postman
- Tailscale
- VsCode
- Zen Browser
- Yazi
